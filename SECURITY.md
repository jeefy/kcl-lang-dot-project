# Security Policy

## Reporting Security Issues

The KCL maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/kcl-lang/kcl/security/advisories/new) form.

For more details, see the [KCL security policy](https://github.com/kcl-lang/kcl/blob/main/SECURITY.md).
